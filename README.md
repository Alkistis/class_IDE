# class_IDE 
### based on CLASS v2.9.3

This repository contains the CLASS code for the "pure momentum transfer" coupled quintessence model first introduced in [Pourtsidou, Skordis and Copeland](https://arxiv.org/abs/1307.0458) (the so-called "Type 3" theories in that paper). This version of the code is using the quadratic coupling function, $\beta Z^2$, and the exponential potential, $V(\phi)=V_0e^{-\lambda \phi}$.
